THEME RULE

All dashboards generated by this skill MUST follow the configured
institutional theme.

The agent MUST NOT:
- randomly choose colors
- introduce gradients
- use neon colors
- use 3D charts
- use decorative backgrounds
- change the primary color system
- use inconsistent card styles

The agent MAY:
- choose different chart types based on the data
- adjust chart density
- change layout based on dashboard purpose
- use semantic colors for success/warning/danger
- use accent colors sparingly

The dashboard must remain visually recognizable as part of
the same dashboard system even when the dataset changes.
